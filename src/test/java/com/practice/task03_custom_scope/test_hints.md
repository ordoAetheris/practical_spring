# Подсказки: Custom Scope (Thread)

## Обязательно протестировать
- Один поток — get дважды возвращает тот же объект
- Два потока — get возвращает РАЗНЫЕ объекты
- remove: следующий get создаёт новый
- cleanup: destruction callbacks вызваны

## Продвинутые кейсы
- Thread pool: потоки переиспользуются — cleanup между задачами обязателен!
- Memory leak: если не cleanup — ThreadLocal держит ссылки после завершения задачи
